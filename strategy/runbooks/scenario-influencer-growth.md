# 🌟 Runbook: 90-Day Influencer Growth Sprint

> **Mode**: NEXUS-Sprint | **Duration**: 90 days (13 weeks) | **Agents**: 5 core specialists

---

## Scenario

You're a content creator who has been posting consistently but plateaued — or you're just starting and want to build the right foundation from day one. This runbook uses the full Influencer Growth Suite to systematically grow your audience, improve content quality, build genuine community, and activate income streams within 90 days.

**This runbook works for creators at any tier:**
- Nano (0–10K): Build foundation, find niche, create first viral content, secure gifted partnerships
- Micro (10K–100K): Accelerate growth, close first paid deals, build community depth
- Mid-Tier (100K–500K): Scale income, diversify revenue, launch owned products or courses

---

## Agent Roster

### Core Growth Team (All 90 Days)
| Agent | Role |
|-------|------|
| Influencer Growth Coach | Strategy director — account audits, roadmaps, weekly check-ins |
| Content Performance Analyst | Data intelligence — post scoring, pattern extraction, experiment tracking |
| Viral Content Architect | Content engineering — hooks, blueprints, trend identification, calendar |
| Audience Intelligence Agent | Community builder — personas, superfan cultivation, DM strategy |
| Brand Deal Strategist | Monetization engine — media kit, outreach, negotiation, income systems |

## Phase 1: Foundation (Weeks 1–2)
**Goal**: Complete account audit, define strategy, build content infrastructure

```
Week 1: Day-by-Day Execution

Day 1 — Account Audit
├── Influencer Growth Coach → Full account audit
│   Input: Platform handles, follower counts, engagement rates, top/bottom posts, goals
│   Output: Profile Health Score, top 3 blockers, initial content recommendations
├── Content Performance Analyst → Pull 90-day metrics baseline
│   Input: Last 90 posts with full metrics (reach, engagement, saves, shares, profile visits)
│   Output: Performance baseline report, initial pattern observations
└── Gate: Review audit findings — are goals realistic? Adjust if needed.

Day 2–3 — Strategy Design
├── Influencer Growth Coach → 30/60/90-day roadmap
│   Input: Audit findings + growth goals
│   Output: Full roadmap with weekly milestones
├── Audience Intelligence Agent → Initial audience audit
│   Input: Platform analytics demographics + comment/DM themes
│   Output: Preliminary audience persona, vocabulary guide, pain/aspiration map
└── Brand Deal Strategist → Monetization readiness assessment
    Input: Account overview + niche + audience demographics
    Output: Income tier assessment, immediate income opportunities, 90-day monetization plan

Day 4–5 — Content Infrastructure Setup
├── Viral Content Architect → 30-day content calendar
│   Input: Growth roadmap + performance analyst findings + audience persona
│   Output: 30-day calendar with topics, hooks, formats, and posting schedule
├── Viral Content Architect → 5 full content blueprints for Week 1
│   Input: Content calendar + creator's viral history + winning formula hypothesis
│   Output: Hook + structure + caption + hashtag blueprints for top-priority posts
└── Influencer Growth Coach → Week 1 sprint checklist
    Input: Audit + roadmap + calendar
    Output: 7 specific actions with deadlines and success criteria

Week 2: Implementation + First Content Cycle

Day 8–10 — First Formula Posts
├── Viral Content Architect → Real-time hook refinement if Week 1 posts underperform
├── Content Performance Analyst → First post performance review (48 hours post-publish)
└── Audience Intelligence Agent → Monitor comment quality and superfan signals

Day 11–12 — Community Strategy Launch
├── Audience Intelligence Agent → Comment section strategy deployment
│   - Pinned comment template for top post
│   - First seed question to drive comments
│   - DM welcome message for new followers
└── Brand Deal Strategist → Media kit draft
    Input: Audience persona + platform stats + content examples
    Output: Complete media kit draft (ready for review)

Day 13–14 — Week 2 Review
├── Content Performance Analyst → Week 1–2 performance assessment
├── Influencer Growth Coach → Strategy adjustment based on first two weeks
└── Gate: Week 2 check — is engagement trending up? Adjust calendar if needed.
```

## Phase 2: Momentum (Weeks 3–6)
**Goal**: Establish consistent posting rhythm, algorithm training, first brand outreach

```
Week 3–4: Algorithm Training Sprint

Weekly Rhythm (Repeat Each Week):
├── Monday: Weekly performance review (Content Performance Analyst)
├── Monday: Content calendar for upcoming week confirmed (Viral Content Architect)
├── Tue–Sat: Execute content calendar — post at optimal times
├── Daily: Active comment engagement (first 60 min after each post)
├── Friday: Superfan check-in — reply to every superfan comment personally
└── Sunday: Prep next week's content hooks and briefs

Key Activations:
├── Viral Content Architect → First trend hijack post
│   Trigger: When a relevant trend hits growth phase (50K–500K videos)
│   Output: Trend-specific content blueprint with niche angle
├── Audience Intelligence Agent → Superfan identification report
│   Input: Comment data from first 30 days
│   Output: Top 20 superfan accounts, outreach plan, community activation events
└── Brand Deal Strategist → Brand outreach campaign launch
    Input: Finalized media kit + target brand list
    Output: First 10 personalized outreach emails sent

Week 5–6: Community Depth + Collaboration

├── Audience Intelligence Agent → First live session strategy
│   Output: Live format, promotion plan, Q&A framework, post-live CTA
├── Viral Content Architect → First collab content blueprint
│   Input: Suggested collab partner from Growth Coach + winning formula
│   Output: Collab content concept with roles, hooks, and cross-posting strategy
├── Content Performance Analyst → 30-day performance report
│   Output: What's working (double down), what isn't (eliminate), A/B experiment results
└── Brand Deal Strategist → Follow-up sequence for Week 3 outreach
    Output: Personalized follow-up emails + 5 new outreach targets
```

│   Output: Community strength score, next-level engagement tactics

│   Input: 60 days of performance data

│   Input: Day 1 metrics vs. Day 90 metrics across all platforms

## Common Pitfalls & Mitigations

| Pitfall | Signal | Mitigation |
|---------|--------|-----------|
| Posting without analyzing | "I'm posting but nothing's changing" | Force weekly Content Analyst review before each week's calendar is finalized |
| Hook quality neglect | Watch time dropping, low completion | Viral Architect rewrites hooks for next 10 posts using formula library |
| Community neglect | Falling comment quality, superfans going quiet | Audience Agent activates superfan re-engagement campaign |
| Underpriced brand deals | Getting offers but still broke | Brand Deal Strategist rate audit — anchor higher on all future offers |
| Niche drift | Engagement suddenly dropping across all content | Influencer Growth Coach niche realignment session |
| Platform dependency | One platform change tanks all results | Audience Agent → migrate top 10% of audience to email/owned channel |
| Perfectionism paralysis | Posting cadence below plan | Viral Architect switches to lower-production formats; ship > perfect |
| Follower growth without engagement | Follower count growing but engagement % falling | Audience Agent → quality-over-quantity audit; pause broad growth tactics |
